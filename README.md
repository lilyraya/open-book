# OPEN
## A Manual for Shared Prosperity

*By Lily Raya*

## The Thesis
This is a living book about radical openness. It argues that our greatest enemies are ignorance, poverty, and mistrust, and that open systems—open source, open data, open borders—are the instruments we need to defeat them.
